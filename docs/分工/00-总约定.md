# ClassRep 分工总约定（四人共同遵守）

> 本文是四个人（和四个 AI）之间的**合同**。每个人的 AI 开工前必须先读：`架构.md` → `需求文档.md` → 本文 → 自己的分工文件。
> 优先级：`架构.md` > 本文 > `需求文档.md`。本文没写的细节，**自己目录内**自由决定；**跨目录的东西**（类型、表结构、函数签名、API 格式）只能按本文来，要改必须在群里说、四人同意、先改本文再改代码。

## 1. 分工一览

| 代号 | 角色 | 一句话 | 需要的电脑 |
|---|---|---|---|
| **A** | 采集端 + 打包 | 让后端自动拉起 NapCat、登录 QQ、收到消息，最后打出压缩包 | **必须 Windows + 已装 QQ 电脑版 + 本机有 `tools/napcat/`**；最好准备一个备用 QQ 号 |
| **B** | 后端骨架 + 数据 + 业务 API | 搭骨架、建库、消息入库、事件查询/修改、.ics 导出、演示接口、/health | 任意（Mac/Windows 都行） |
| **C** | AI 流水线 | 规则过滤 → LLM 提取 → 事件合并；写仿真数据 | 任意，需要一个 LLM API Key |
| **D** | 前端 | 今日/本周/详情/群管理/扫码连接/演示控制台，手机适配 | 任意 |

## 4. 共享类型 `apps/server/src/types.ts`（逐字照抄）

```ts
// ===== 时间约定：所有时间一律为「毫秒时间戳 number」（数据库、函数、API 全部如此）。
// ===== 只有在「给 LLM 的 prompt」「.ics 文件」「页面显示」这三处才转成 Asia/Shanghai 文本。
// ===== 所有 id（群号、消息 id）一律为 string。

export type EventType = 'exam' | 'assignment' | 'meeting' | 'activity' | 'announcement' | 'other';
export type EventStatus = 'active' | 'cancelled' | 'done' | 'pending_confirm';
export type ConnectState =
  | 'qq_conflict' | 'error' | 'kicked' | 'online' | 'waiting_qr' | 'reconnecting' | 'starting';
export type MessageSource = 'onebot' | 'history' | 'demo' | 'import';

/** 所有来源最终都转成它再入库 */
export interface Message {
  message_id: string;   // onebot/history: String(message_id)；demo: `demo-<剧本名>-<序号>`；import: `import-<时间戳>-<序号>`
  group_id: string;     // demo/import 的群号以 `demo-` 开头
  group_name: string;
  sender_name: string;  // 只存昵称，不存 QQ 号
  text: string;         // 已把消息段转成纯文本（[图片]、[at] 等占位符）
  sent_at: number;
}

export interface EventDTO {
  id: number;
  group_id: string;
  group_name: string;
  type: EventType;
  title: string;
  description: string;
  start_at: number | null;
  end_at: number | null;
  deadline_at: number | null;
  location: string | null;
  action_required: string | null;
  status: EventStatus;
  confidence: number;   // 0~1
  version: number;
  created_at: number;
  updated_at: number;
}

export interface SourceMessageDTO {
  message_id: string;
  sender_name: string;
  text: string;
  sent_at: number;
}

export interface HistoryDTO {
  version: number;
  changed_fields: Record<string, { from: unknown; to: unknown }>;
  source_message_id: string | null;
  changed_at: number;
}

export interface EventDetailDTO extends EventDTO {
  sources: SourceMessageDTO[];
  history: HistoryDTO[];
}

export interface TodayDTO {
  date: string;         // 'YYYY-MM-DD'（Asia/Shanghai）
  summary: string;      // 如 "今天 4 件事，最急的是 14:00 高数小测"；没有事件时 "今天没有待办，轻松一天"
  events: EventDTO[];
}

export interface GroupDTO {
  group_id: string;
  name: string;
  enabled: boolean;
  message_count: number;
  event_count: number;
}

export interface ConnectStatusDTO {
  state: ConnectState;
  uin?: string;
  since: number;        // 进入当前状态的时间
  message?: string;     // error 时的用户文案（架构.md §7）
  first_run: boolean;   // 从未登录过（无 uin）且库里没有任何消息/事件 → 前端拦到 /connect
}

export interface PipelineStats {
  filtered_count: number;    // 累计被规则过滤掉的消息数
  llm_called_count: number;  // 累计 LLM 调用次数
  llm: 'ok' | 'error' | 'unconfigured';  // 最近一次调用结果；没配 key 为 unconfigured
}

export interface HealthDTO extends PipelineStats {
  status: 'ok' | 'degraded';
  db: 'ok' | 'error';
  qq: ConnectState;
  jev: 'disabled';
  uptime: number;       // 秒
}
```

## 5. 数据库（`data/classrep.db`，B 建表，其他人按此读写）

```sql
CREATE TABLE IF NOT EXISTS groups (
  group_id   TEXT PRIMARY KEY,
  name       TEXT NOT NULL,
  enabled    INTEGER NOT NULL DEFAULT 1,
  adapter    TEXT NOT NULL,              -- MessageSource
  created_at INTEGER NOT NULL
);
CREATE TABLE IF NOT EXISTS messages (
  message_id   TEXT PRIMARY KEY,
  group_id     TEXT NOT NULL,
  sender_name  TEXT NOT NULL,
  text         TEXT NOT NULL,
  sent_at      INTEGER NOT NULL,
  source       TEXT NOT NULL,            -- MessageSource
  processed    INTEGER NOT NULL DEFAULT 0,   -- C 处理完置 1
  filtered_out INTEGER NOT NULL DEFAULT 0,   -- C 规则过滤掉置 1
  created_at   INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_messages_group_time ON messages(group_id, sent_at);
CREATE INDEX IF NOT EXISTS idx_messages_processed  ON messages(processed);
CREATE TABLE IF NOT EXISTS events (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  group_id        TEXT NOT NULL,
  type            TEXT NOT NULL,
  title           TEXT NOT NULL,
  description     TEXT NOT NULL DEFAULT '',
  start_at        INTEGER, end_at INTEGER, deadline_at INTEGER,
  location        TEXT, action_required TEXT,
  status          TEXT NOT NULL DEFAULT 'active',
  confidence      REAL NOT NULL,
  version         INTEGER NOT NULL DEFAULT 1,
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL
);
-- 来源消息存「快照」：原始 messages 7 天后被清理，详情页的「查看来源」仍要能看
CREATE TABLE IF NOT EXISTS event_sources (
  event_id    INTEGER NOT NULL,
  message_id  TEXT NOT NULL,
  sender_name TEXT NOT NULL,
  text        TEXT NOT NULL,
  sent_at     INTEGER NOT NULL,
  PRIMARY KEY (event_id, message_id)
);
CREATE TABLE IF NOT EXISTS event_history (
  id                INTEGER PRIMARY KEY AUTOINCREMENT,
  event_id          INTEGER NOT NULL,
  version           INTEGER NOT NULL,
  changed_fields    TEXT NOT NULL,       -- JSON：Record<字段, {from,to}>
  source_message_id TEXT,
  changed_at        INTEGER NOT NULL
);
```

**谁写哪张表**：`groups` / `messages` 的插入 → B（`ingestMessages`）；`messages.processed/filtered_out` → C；`events` / `event_sources` / `event_history` 的新建与合并 → C；用户手动改状态（PATCH）和删群数据 → B。

## 6. 模块之间的函数（签名逐字照抄）

| 文件（主人） | 导出 | 说明 |
|---|---|---|
| `db/index.ts`（B） | `openDb(): void`、`db: DatabaseSync` | `node:sqlite` 的实例；`openDb` 建表 |
| `paths.ts`（B） | `ROOT, DATA_DIR, NAPCAT_DIR, WEB_DIST, MOCK_DIR: string` | `ROOT` = 从本文件所在目录往上找、第一个包含 `启动.bat` 的目录（仓库根和压缩包根都有）。`NAPCAT_DIR = ROOT/napcat`；`WEB_DIST` 取 `ROOT/app/web/dist`（压缩包）或 `ROOT/apps/web/dist`（开发）中存在的那个 |
| `ingest/index.ts`（B） | `ingestMessages(msgs: Message[], source: MessageSource): { inserted: number }` | 同步函数。群不存在则登记（enabled=1）；群名变了更新；**群 enabled=0 的消息直接丢弃不入库**；`INSERT OR IGNORE` 按 message_id 去重 |
| `ingest/index.ts`（B） | `upsertGroup(group_id: string, name: string, adapter: MessageSource): void` | A 在 `get_group_list` 后调用刷新群名 |
| `napcat/index.ts`（A） | `startNapcat(): void`、`stopNapcat(): void` | 非 Windows（`process.platform !== 'win32'`）时 `startNapcat` 什么都不做 |
| `napcat/state.ts`（A） | `getConnectStatus(): ConnectStatusDTO` | 非 Windows 时返回 `state:'error', message:'当前系统不支持采集端（开发模式，可用演示回放）'` |
| `napcat/onebot.ts`（A） | `callAction<T = unknown>(action: string, params: object, timeoutMs?: number): Promise<T>` | 未连接时 reject |
| `ingest/history.ts`（A） | `syncHistory(): Promise<{ groups: number; messages: number }>` | FR-2 |
| `pipeline/index.ts`（C） | `startScheduler(): void`、`runPipelineNow(): Promise<void>`、`getPipelineStats(): PipelineStats` | 调度器自己轮询 `messages.processed=0`，**别人入库后不需要通知它**；演示回放后调 `runPipelineNow()` 立即处理 |
| `routes/business.ts`（B） | `registerBusinessRoutes(app: Hono): void` | |
| `routes/connect.ts`（A） | `registerConnectRoutes(app: Hono): void` | |

**启动顺序（B 的 `index.ts`）**：读 `.env` → `openDb()` → 建 Hono app → 局域网只读中间件 → `registerBusinessRoutes` → `registerConnectRoutes` → 静态文件 → 监听（8000 起顺延）→ `startScheduler()` → `startNapcat()` → 启动清理任务 → 打包版才自动打开浏览器。退出信号里调 `stopNapcat()`。

**环境变量（`.env`，开发时放仓库根，打包后在 `app/.env`）**：`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`（**连接页「AI 接入」保存的 key 存在 `data/llm.json`，优先于 `.env`，保存后立即生效**）、`AUTO_EXIT`（`1` = 后台模式，网页全关后自动退出；由 `scripts/dev.mjs --background` 设置，平时不用填）、`DEMO_MODE`（`true` 才允许 reset，默认 `true`）、`RAW_MSG_TTL_DAYS`（默认 7）。仓库里放一份不含 key 的 `.env.example`（B）。

## 7. HTTP API（前端 D 只依赖这些）

所有接口返回 JSON，出错返回 `{ "error": "给人看的中文" }` + 4xx/5xx。**来自局域网（非 127.0.0.1/::1）的非 GET 请求一律 403。**

| 方法 路径 | 主人 | 请求 | 返回 |
|---|---|---|---|
| `GET /health` | B | — | `HealthDTO` |
| `GET /api/today` | B | — | `TodayDTO`：`start_at` 或 `deadline_at` 落在今天（上海时间）的事件，状态不是 `cancelled`，按时间升序 |
| `GET /api/events?from=&to=` | B | from/to 为毫秒，可省略 | `EventDTO[]`：`start_at`/`deadline_at` 落在区间内；都省略时返回全部非 cancelled。`start_at` 和 `deadline_at` 都为空的事件只在都省略时返回 |
| `GET /api/events/:id` | B | — | `EventDetailDTO`（sources 按时间升序，history 按 version 升序） |
| `PATCH /api/events/:id` | B | `{ status: EventStatus }` | `EventDTO` |
| `GET /api/export.ics?from=&to=` | B | 同上 | `text/calendar` 文件 |
| `GET /api/events/:id/export.ics` | B | — | 单条 `text/calendar` |
| `GET /api/groups` | B | — | `GroupDTO[]` |
| `PATCH /api/groups/:id` | B | `{ enabled: boolean }` | `GroupDTO` |
| `DELETE /api/groups/:id/data` | B | — | `{ ok: true }`：删该群 messages/events/sources/history，群本身保留 |
| `GET /api/demo/scenarios` | B | — | `{ name: string; title: string; count: number; group_id: string; active: boolean }[]`：`active` = 该剧本的演示群里当前有数据（回放过且没取消） |
| `POST /api/demo/replay` | B | `{ scenario: string }` | `{ injected: number }`，注入后已调用 `runPipelineNow()` |
| `POST /api/demo/reset` | B | — | `{ ok: true }`：删除所有 `demo-` 开头的群及其数据；`DEMO_MODE!=true` 时 403 |
| `POST /api/demo/undo` | B | `{ scenario: string }` | `{ ok: true }`：取消某个剧本的回放，只删这个剧本对应的演示群及其数据；剧本不存在 404；`DEMO_MODE!=true` 时 403 |
| `POST /api/import/text` | B | `{ groupName: string; text: string }` | `{ messages: number }` |
| `GET /api/connect/status` | A | — | `ConnectStatusDTO` |
| `GET /api/connect/qrcode` | A | — | PNG，不存在 404 |
| `POST /api/connect/restart` | A | — | `{ ok: true }` |
| `POST /api/sync` | A | — | `{ groups: number; messages: number }`；未连接时 409 `{error:"QQ 未连接"}` |
| `GET /api/settings/llm` | D | — | `{ provider: 'deepseek'; configured: boolean; key_hint: string; source: 'web' | 'env' | 'none' }`，key 只返回打码提示（如 `sk-****367f`），不回传明文 |
| `PUT /api/settings/llm` | D | `{ provider: 'deepseek'; api_key: string }` | 同上；key 为空或不是 `sk-` 开头 → 400 |
| `GET /api/presence?id=` / `POST /api/presence/bye?id=` | D | — | `{ ok: true }`：**仅后台模式（`AUTO_EXIT=1`）存在**，网页心跳 / 关页面时说再见，最后一个网页关掉约 15 秒后后端自动退出 |

## 8. 仿真剧本格式（`data/mock/<name>.json`，C 写，B 回放）

```json
{
  "title": "改期场景",
  "group": { "id": "demo-math", "name": "高数(2)班" },
  "messages": [
    { "offset_minutes": -180, "sender": "张老师", "text": "@全体成员 明天下午两点在 A301 随堂小测，带计算器" },
    { "offset_minutes": -179, "sender": "小王", "text": "收到" },
    { "offset_minutes": -5,   "sender": "班长", "text": "[at] 小测改到周五下午两点，教室改 A203" }
  ]
}
```

- `sent_at = 回放时刻 + offset_minutes 分钟`；**文本只写相对时间**（明天、周五、下周三），绝不写具体日期。
- 一个文件一个群；`message_id = demo-<文件名>-<序号>`。

## 9. 协作流程（小白版）

1. **第 0 步（B 先做，其他人等它合进 main）**：B 用半天内提交骨架——§3 所有文件都建好，§6 的函数全部写成**能编译的空实现**（返回假数据），`pnpm dev` 能打开一个空白页面。之后其他三人从 main 拉分支开工，每人只把自己的空实现换成真实现。
2. 每人一个分支：`feat/a-napcat`、`feat/b-backend`、`feat/c-pipeline`、`feat/d-web`。**每完成一个小功能就合进 main**（至少每天一次），不要攒一周。
3. 合并前必须：`pnpm -r typecheck` 通过、`pnpm -r test` 通过、`pnpm dev` 能启动。
4. 发现需要改 §4~§8 的任何东西：先在群里说 → 改本文 → 再改代码 → 通知大家 `git pull`。
5. 让 AI 干活时，一次只给它一个任务（分工文件里的一行），做完、自测、提交，再给下一个。

### 9.1 开发时一键启动 / 重启

| 方式 | 效果 |
|---|---|
| 桌面快捷方式「ClassRep 启动」（第一次运行 `pnpm shortcut` 生成） | **后台模式**：不弹黑框，自动打开 http://localhost:8000；**网页全部关掉约 15 秒后自动退出**；日志在 `data/logs/background.log` |
| 双击 `scriptsdev-start.bat` 或 `pnpm start` | **前台模式**：黑窗口里看日志，关窗口即退出 |

两种方式都会先结束占着 8000~8010 端口的旧 ClassRep 后端、重新打包前端，所以**再运行一次就是重启**，不会再出现「8000 被占用」。
