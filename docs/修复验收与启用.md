# 功能使用与验收边界

## 获取与更新

首次使用可克隆仓库后双击 `启动.bat`：

```powershell
git clone https://github.com/wahha696/Minicamp-AIClassRep.git
Set-Location Minicamp-AIClassRep
.\启动.bat
```

已有源码用户先在应用中备份数据，关闭自己打开的启动窗口，确认没有需要保留的未提交代码后执行 `git pull --ff-only origin main`，再运行 `启动.bat`。有本地改动时先另行保存，不使用强制重置覆盖。访问本次启动器显示的网址；关闭网页不会关闭旧后端。

每个安装目录独立保存数据和配置。重新克隆不会自动读取其他安装的账号或 AI Key；迁移数据使用应用备份与恢复流程，不直接覆盖正在使用的数据库。源码更新不会自动发布新的免安装 ZIP。

## 功能与边界

| 功能 | 当前行为 |
| --- | --- |
| 首次启动配置 AI | 支持自定义兼容端点、模型和 Key，测试成功再保存。鉴权成功不等于所有模型都支持相同输出格式或抽取质量。 |
| 微信状态 | 采集中为绿，其余已知连接状态为红；健康接口整体不可达时查看应用连接错误。 |
| 微信目录记忆 | 按安装身份和账号隔离；缺少身份时不读写缓存。旧版仅账号缓存不迁移；目录记忆不代替读取授权。 |
| 学期第一周 | 空白课表默认 2026-09-07，可编辑；已有课表、导入结果和草稿优先，不覆盖用户选择。 |
| 助手与长期偏好 | 用户确认计划后执行真实业务入口。偏好可查看、修改、启停、删除和查看来源；排除规则仅影响精确绑定课程的后续新建事项，普通 note 只作为助手上下文。 |
| 历史补齐 | QQ 登录自动、旧同步接口和手动補齐共用后台任务；进度持久化、按页去重，切换账号拒收旧回执。微信通过心跳区分处理较慢与无响应。 |

## 单次课程完成

本周页两种视图均可完成或撤销具体日期、具体时段的一次课程；助手使用相同入口。操作不会完成整门课、整个学期或未来同名课程。

服务端核对课表版本、课次 ID、日期和起止时间。调课、停课以及课程名称或时间变化不会继承旧课次状态；仅地点调整保留状态。清空课表后当前页面没有完成项，但历史记录保留，恢复相同版本可恢复对应标记。整库重置会清除完成记录。

## 历史任务恢复

刷新或关闭浏览器不终止后台任务。旧 `/api/sync` 返回 `202 {job}`，客户端应查询任务状态，不能把它当作已完成数量。控制请求失联代表结果未知，不能据此反复启动任务。

QQ 请求超过 180 秒只提示继续等待，不丢弃迟到结果；用户可主动取消，连接断开时释放等待。微信进程或服务重启后的中断任务需要重新建立采集授权并继续。恢复会重扫原时间窗口并通过回执去重；仅能读取客户端实际保留的记录，不保证远端历史完整。

## 验收边界

合成数据测试覆盖读取、去重、账号隔离、取消、恢复、偏好流水线、助手确认、课次状态及数据库迁移。自动测试和无凭据启动命令见[源码安装与验证](源码安装与验证.md)。

干净目录及 CI 验证不能替代另一台电脑上的真实登录、数据库采集和完整使用验收。微信目前仍限于已验证的 4.1.15.50 模块指纹，相同版本号不保证相同构建。其他版本不能通过删除检查宣称兼容；详见[首次启动与环境依赖](首次启动与环境依赖.md)。
