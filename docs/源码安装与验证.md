# 从干净克隆安装与验证

## Windows 安装

支持 Windows 10/11 x64。需要联网下载公开依赖；连接 QQ、微信和 AI 服务还需要用户自己的客户端、登录和凭证。

```powershell
git clone https://github.com/wahha696/Minicamp-AIClassRep.git
Set-Location Minicamp-AIClassRep
.\启动.bat
```

首次启动会准备 Node、pnpm 依赖、便携 Python、前端构建及所需采集组件。Python 下载来自 python.org，包来自 PyPI；网络不通会明确失败，可修复网络后重试。运行数据与个人配置不会随 Git 克隆。

已有 Node.js 24 LTS（最低 22.16）和 pnpm 10.34.5 的开发者也可逐步运行：

```powershell
pnpm install --frozen-lockfile
node scripts/fastjudge-setup.mjs
pnpm typecheck
pnpm build
pnpm start
```

`fastjudge-setup.mjs` 在仓库的 `classrep-fastjudge/py/` 创建独立便携 Python，并验证快判依赖及固定的 zstandard 0.25.0。它不读取微信、不导入个人配置。不能用其他目录已有的 Python 代替微信所需便携运行时。已安装且依赖齐全时复用。

`pnpm start` 不拉取 Git 更新；原实例仍运行时会复用它。修改后端后，请先 Ctrl+C 正常退出原实例再启动。关闭网页不会退出后端。`pnpm dev:start` 包含 Git 更新，不适合作为固定版本验证入口。

## 用户必须配置的部分

- AI：首次引导与设置页共用配置表单，可选 DeepSeek 或自定义 OpenAI 兼容服务，填写接口地址、API Key 和模型；模型可留空，由连接检查选取服务返回的模型。检查和保存成功后才继续引导。也可复制 `.env.example` 为 `.env`。未配置凭证可打开应用，但不能完成云端整理。日程提取、偏好总结及助手对话可能把相关文本和上下文发送给所配置的服务。
- QQ：需要已安装 QQ NT 电脑版及本人登录。NapCat 为第三方组件，版本支持依实际客户端而定；缺组件时可按页面提示下载，版本固定在 `napcat.version.json`。
- 微信：需要本机已登录的 Windows 微信。当前仅对 4.1.15.50 指定模块构建有验证证据；其他构建可能被拒绝。连接后在群管理填入以 `xwechat_files` 结尾的存储位置，读取目录，再明确开启需要的群。顶部状态灯未采集时为红色，正在采集时为绿色。
- 路径记忆：微信路径仅保存在当前浏览器，并按安装身份和微信账号共同隔离；安装身份尚未就绪时不读写缓存。不自动迁移旧版仅按账号保存的值，升级或换安装目录后可能需要重填。浏览器站点数据不属于 Git 仓库；不同克隆即使使用同一 localhost 地址，也不复用另一安装的路径偏好。路径缓存不保存读取授权或凭证。
- 课表：导入预览或手动创建时，若文件及已有课表都没有日期，“第一周周一”默认 `2026-09-07`。可自行修改；默认值不覆盖已保存日期、导入日期或正在编辑的草稿。请核对校历后保存。
- 历史：在群管理使用“补拉历史”，QQ 与微信分别运行持久化后台任务。任务没有总耗时截止，页面刷新后继续读取已有任务进度，不重复启动；可查看已入库消息数、群进度和失败原因。取消会在安全边界停止，已保存数据保留；断连或后端重启后可恢复重试，按已有记录去重。失联、无响应和游标停滞仍会被检测并明确报告，不把正常长耗时当作失败。只能补回客户端实际保留的记录；图片、语音等未支持内容不会自动 OCR 或转写。任务已提交、消息已入库不等于 AI 整理已完成。
  QQ 没有单页心跳，180 秒无回应只显示仍等待、处理状态未知，不会终止原请求；迟到结果仍正常接收，也可主动取消等待。微信读取期间每 10 秒发送私有心跳，180 秒无心跳才按失联处理。微信重启后可能重读失败群的已读前缀，仍按原时间窗和回执去重，并跳过完成群。

应用自动创建 SQLite 库并执行迁移。已有库迁移前会生成备份，须留足磁盘空间；不要手工复制正在运行的 SQLite 主文件来替代完整备份。

## 桌宠助手与长期偏好

桌宠使用用户配置的 LLM 提出应用操作，查询和修改范围以助手“我能做什么”中的实际工具列表为准。写操作先展示对象、参数和范围，必须点击确认；聊天中回复“确认”不会执行旧计划。账号、空间或会话改变后旧计划失效，同一计划重复确认不会重复执行。登录、凭证输入、文件选择等仍需在对应页面由本人完成。

长期偏好可查看、修改、停用或删除，仅在当前空间生效。排除日程规则必须指定课程和事项类型，并且群已绑定该课程；未绑定课程时不会只凭标题猜测排除。匹配规则影响后续新事项，保留未加入日程记录及原消息来源供核对，不删除已有事项或源聊天。主动清理群数据时会删除该群相关的来源记录；备份仍需用户单独管理。

## 备份与恢复

设置页导出的是当前业务空间数据。登录态、AI Key、微信读取许可和采集回执不属于便携备份。恢复会保留恢复前数据库和微信回执备份，停用旧回执，并关闭恢复库中的微信群采集；需重新读取目录、明确开启群并按需补历史，避免沿用不匹配的游标或旧授权。业务原文和事项不会因此删除。空间无法安全挂载时，不会猜测 QQ 目录作为恢复目标。

## 自动化检查

全部使用模拟消息与临时数据库，不需要真实微信登录或 AI Key。

```powershell
node scripts/fastjudge-setup.mjs
$env:WECHAT4_TEST_PYTHON = (Resolve-Path .\classrep-fastjudge\py\python.exe).Path
pnpm test
node scripts/test-wechat-python.mjs
node --test scripts/lib/*.test.mjs scripts/update.test.mjs scripts/rescue-upgrade.test.mjs
pnpm typecheck
pnpm build
git diff --check
```

`node scripts/smoke-clean.mjs` 用构建后的后端启动无凭证本地冒烟实例，禁用真实 QQ 注入并拒绝非本地网络请求，检查首页、数据库初始化和零 AI 调用后退出。只应在没有个人配置和运行数据的干净检出中执行；脚本发现个人数据目录或 `.env` 时会拒绝。

Docker/Linux 目录目前仅作为开发参考，不是微信支持环境，也没有本轮容器运行验收；请勿把 Windows 安装步骤或安全访问边界直接等同于容器部署。
