# 教师蒸馏成本指南（train/COST.md）

> 目的：把"花了多少钱、花在哪、怎么少花"变成可测量的事。数字来自本机跑批日志与探针实测，
> 单价随官方调整 —— 用环境变量覆盖后再看估算：
> `TEACHER_PRICE_HIT` / `TEACHER_PRICE_MISS` / `TEACHER_PRICE_OUT`（元/百万 token，默认 0.5 / 2 / 8）。

## 一句话结论

**贵的是"生成剧本"这一步的输出 token（¥8/百万），不是蒸馏。**
蒸馏的输入里约 89% 是同一条 system prompt 的重复，但**实测缓存命中率 91.3%**，
命中价只要 ¥0.5/百万 —— 蒸馏侧其实已经很便宜了。

## 实测用量

| 阶段 | 调用 | 输入 tok | 输出 tok | 估算 ¥ | 说明 |
|---|---|---|---|---|---|
| v2 剧本生成（600 例 → 554） | 585 | 367,520 | 694,115 | ~¥6.3 | 输出是大头 |
| v2 教师蒸馏（→ 675 对） | 773 | 1,715,279 | 163,101 | ~¥2.1 | 输入未计缓存 |
| v3 剧本生成（1800 例 → 1773） | ~1,800 | ~1,060,000 | ~2,020,000 | ~¥18.3 | **本轮最贵的一步** |
| v3 增量蒸馏（累计 2,795 对） | 3,123 | 7,046,965 | 728,493 | ~¥10.3 | 命中 91.3%，输入实付 ~¥4.5 |
| **合计** | ~6,300 | ~10.2M | ~3.6M | **~¥37** | 约 5 美元量级 |

单次调用画像（蒸馏）：`7,046,965 ÷ 3,123 ≈ 2,257 tok/次`，其中 system prompt ≈ 2,000 tok。

## 探针实测（9 次调用，¥0.03）

```
调用 9 次（失败 0），输入 18499 tok（缓存命中 16896 / 91.3%） + 输出 2006 tok ≈ ¥0.03
```

`train/lib/teacher.ts` 现在会自动打印这一行 —— **没有这个命中率，任何"省钱"都是猜。**

## 省钱杠杆（按实测性价比排序）

### 1. 不要重复生成剧本（最省）
剧本生成按输出计费，每个剧本 ≈ 1,100 个输出 token。已经付过钱的 2,342 个剧本要反复利用：
- 增量蒸馏 `--out` 指向已有 jsonl，会自动跳过已完成的 `scenario#batch`，**不重复花钱**；
- 想扩样本量时，优先"同一批剧本换 `now` 再蒸一遍"（输入侧、命中缓存、便宜约一个数量级），
  而不是新生成剧本。⚠️ 需要改一处代码：去重键目前是 `scenario#batch`，
  换 `now` 会被误判成重复而跳过 —— 应把 `now` 偏移量并入键（`scenario#batch@offset`）。

### 2. 提高 `--max-candidates`（蒸馏侧的调用次数）
`gen-sft-data.js --max-candidates N`：一个剧本打成的批次越少，重复的 system prompt 越少。
上限目前 30。**别超过生产实际批大小**（训练批形态要贴近 `extract.ts` 的真实请求），
否则学生模型会训到分布外。

### 3. 负样本别找教师
正确标签就是 `{"events": []}` 的剧本（`near_miss`、部分 `chat`）可以让规则直接产出。
当前负例占 24%，能省下其中一部分调用。

### 4. GPU 侧（不是 API 钱，是时间/电费）
- 数据够大时 **1 epoch 足够**：v3 = 2,715 对 × 1 epoch ≈ 170 步 ≈ 5 小时；
  对比 v1 = 358 对 × 3 epoch = 1,074 次样本更新，v3 一遍就有 2,715 次。
- `--drop-over-seq` 丢掉超长样本，别为几个样本拉长整批。
- `--save-steps 25` + 任务计划托管 + `--resume`：实测两次长训练被杀，一次损失 120/126 步。

## 到手册 5k 配方还要多少钱

从当前 2,795 对补到 ~5,000 对 ≈ 再要 ~1,500 个剧本：

| 做法 | 估算 |
|---|---|
| 新生成 1,500 剧本 + 蒸馏 | 剧本 ~¥15 + 蒸馏 ~¥8 ≈ **¥23** |
| 复用已有剧本 + 多 `now` 偏移再蒸（需改去重键） | 纯输入侧、命中缓存 ≈ **¥6~9** |

## 跑批前花钱自检

```powershell
# 1) 只构建 prompt，不调 API
node train\dist\train\gen-sft-data.js --out sft-probe.jsonl --dryrun
# 2) 小步试水：看单例成本与缓存命中率（v3 探针只花了 ¥0.03）
node train\dist\train\gen-sft-data.js --out sft-probe.jsonl --limit 20 --concurrency 1
# 3) 核对单价假设后再看估算
$env:TEACHER_PRICE_HIT='0.5'; $env:TEACHER_PRICE_MISS='2'; $env:TEACHER_PRICE_OUT='8'
```

> 铁律：教师数据一旦产出就复用；`PROMPT_VERSION` 变过才需要重蒸（旧数据同时作废）。
