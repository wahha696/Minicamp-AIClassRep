# 角色 B 任务卡 · 闲聊干扰（群里的气氛组）

> **你的定位**：你负责制造"乱"。产品要证明的第一件事就是
> **"群里几百条闲聊里，只有该记住的那几条被记住了"**——没有你，这个对比就不存在。
>
> 你发的消息**全都不该出现在看板上**，而应该变成「演示」页上跳动的**「累计过滤」**数字。
> 你演得越像真的群，效果越好。

- 你的 QQ 昵称建议改成：`陈晨` 或 `🍊橘子`（路人感越强越好）
- 你要发的全部内容在 `01-话术库` **第七类（闲聊与噪声）**
- 时长：穿插全场，四轮，每轮 1~2 分钟

## 投递脚本

### 第 1 轮 · A 发通知的时候，你在旁边"刷屏"（最重要的对比）

**时机**：主持人说"老师开始发通知"之后，**A 发完第一条通知（A1）你就开始**。

**发什么**（一条一条发，每条间隔 1~2 秒，连发完）：
```
收到
好的
ok
嗯嗯
哈哈哈
+1
谢谢！
知道了
666
```
→ 期待：全部不进看板；「演示」页的**「累计过滤」上涨**。

**然后停 10 秒**，让主持指着数字说："这些是规则层直接丢掉的，一条都没花 AI 的钱。"

### 第 2 轮 · 长一点的闲聊，逼 Jev 出手

**时机**：主持说"再看聪明一点的过滤"。

```
第三章我一点没看
我也是
有人知道这题怎么做吗，求导那块卡住了
用链式法则，先对外层求导
懂了懂了 谢谢
有没有人在图书馆
帮我占个座
二食堂的红烧肉绝了
困了
```
→ 期待：全部不进看板；**「Jev 快判过滤」**数字上涨（和上一轮的"累计过滤"是两个不同的计数器）。
主持会讲："第一个数字是死规则丢的，第二个是快脑判断丢的，**AI 提取一次都没调**。"

### 第 3 轮 · 诱饵（给主持留一个"讲不确定性"的机会）

**时机**：主持说"我们故意留了两条模棱两可的"。

```
明天的题难不难啊
这周还有几节课
```
→ 期待：**可能留下、也可能被丢**。两种结果都能讲：
- 被丢 → "快脑认为没信息，丢了"
- 留下 → "拿不准的它不硬判，等 8 秒凑上下文交给 AI 复核——**宁可多花一次调用，也不漏通知**"

### 第 4 轮 · 表情与占位符（验证"图片/表情不会把流水线搞崩"）

**时机**：任意时刻，主持说"发点图片和表情"。

```
[表情]
[图片]
[表情]
```
→ 期待：不崩、不断连、不生成事件。

> 现场最好真的发 1~2 个**真实表情和图片**（而不是打字 `[表情]`），
> 这样能证明"真实消息段解析"也稳。

## 跟主持人的配合

| 主持人的话 | 你的动作 |
|---|---|
| "群里平时是这样的" | 开始第 1 轮刷屏 |
| "再看聪明一点的过滤" | 第 2 轮，长闲聊连发 |
| "我们故意留了两条模糊的" | 第 3 轮诱饵 |
| "发点图片表情看看" | 第 4 轮，发真实表情/图片 |
| "先安静一下" | **立刻停手**，10 秒内一个字都不发（C 的改期需要安静 3 秒才会触发） |

> ⚠️ **C 演改期的时候你绝对不能刷屏**。你一说话，处理时间就往后推，改期效果会慢半拍。

## 救场话术

| 情况 | 你怎么说 / 怎么做 |
|---|---|
| 你的闲聊**上板了** | 立刻小声告诉主持（这是个真问题）；主持可以顺势说："这条确实模糊，我们记下来，会后调 Jev 阈值" |
| 过滤数字不动 | 可能是数字是"本次启动后"的累计 —— 让主持刷一下「演示」页；仍不动就记下来 |
| 主持说"停" | 真停。你的一条玩笑话可能让整批延后 3~10 秒 |
| 有人问"为什么这些不算事项" | 你的标准答案："**没有具体时间、不需要谁去做什么的事，就不该占我的日程。**" |
