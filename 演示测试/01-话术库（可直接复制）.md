# 话术库（可整段复制）

> 用法：直接复制【】里的内容发到测试群。**不要改字**——每条都对应一个具体的验收点。
> 每条后面的「→ 期待」是页面上应该出现的结果，用来当场对答案。
> 时间一律用**相对时间**（明天 / 周五 / 下周三），任何一天演示都不会穿帮；
> 标注 ★ 的是演示必发条目。

## 第一类 · 课程通知与作业（角色 A 主力）

**A1 ★ 随堂小测（考试 / 紧急）**
```
【@全体成员 明天下午两点在 A301 随堂小测，范围第三章导数与微分，带计算器和学生证】
```
→ 期待：今日页出现红色系卡片「考试」，等级偏深（**紧急**），地点 A301，要求里含"带计算器和学生证"。

**A2 作业布置（作业 / 中）**
```
【本周五 23:59 前把高数第三章习题 3-1 到 3-15 交到学习通，拍照上传即可】
```
→ 期待：橙色系卡片，DDL 为**本周五 23:59**，卡片带 DDL 角标。

**A3 补课（考试类 / 中）**
```
【@全体成员 周三下午 5-6 节的高数调到周四 7-8 节补，教室还是 B203，别跑空】
```
→ 期待：蓝色或红色系卡片，落在**周四 16:00–17:40** 那一格（本周网格形态的"第 4 块"）。

**A4 实验报告（作业 / 紧急）**
```
【大物实验报告本周日 18:00 截止，交到实验楼 A404 门口的作业箱，逾期不收】
```
→ 期待：橙色系、等级**紧急**（24–48 小时内），DDL 周日 18:00。

**A5 没有截止时间的作业 → 应该进"待办"而不是日历**
```
【课设开始准备了，先自己定题目，具体截止时间等老师通知】
```
→ 期待：出现在今日页的**「待办」框**里，而不是时间轴；后面 A6 补了 DDL 之后它会**自动离开待办**。

**A6 给 A5 补上截止时间（演示"待办 → 日历"的流转）**
```
【课设定题报告下周一上午 10:00 前交，文档发我邮箱】
```
→ 期待：待办框里那条**消失**，今日/本周出现带 DDL 的作业卡片。

## 第五类 · 变更（角色 C 主力，**全场最高光的 4 分钟**）

> C 的发法：**一条消息只改一个字段**，每条间隔 10 秒以上，让页面一条条变。

**C1 ★ 改期 + 换教室（基于 A1 的"明天下午两点 A301 小测"）**
```
【@全体成员 小测改到周五下午两点，教室改 A203】
```
→ 期待（核心验收点）：**还是同一张卡片**，没有多出第二条；
卡片出现「已按最新通知更新」；点开详情 →「变更记录」里能看到 `~~旧时间~~ → 周五 14:00`、
地点 `~~A301~~ → A203`；「查看来源」里两条原始消息都在（原通知 + 改期通知）。

**C2 补充要求（合并而不是覆盖）**
```
【另外小测要带草稿纸，计算器别忘了】
```
→ 期待：详情里「要求」变成 **原要求 + 新要求** 的合并结果，旧要求不丢。

**C3 连续改第二次（多条变更记录叠起来）**
```
【@全体成员 小测再推迟一天，改到周六上午十点，教室换成 A305】
```
→ 期待：同一张卡片，变更记录里累计两条；最终时间 = 周六 10:00、地点 A305。

**C4 改会议地点（基于 M1 的班会）**
```
【班会改到 B301，时间不变，还是周四晚上 19:00】
```
→ 期待：会议卡片地点更新，时间保持 19:00 不变。

**C5 细化时间（从"上午"到具体时刻）**
```
【奖学金材料截止时间明确一下，是下周一上午 11:00，不是全天】
```
→ 期待：DDL 从"当天 23:59"精确到 11:00。

## 第七类 · 闲聊与噪声（角色 B 主力）

> B 的任务就是**制造"没变成日程"的对照**。
> 刷得越自然越好，但**不要一次刷超过 15 条**（攒够 15 条会提前触发处理，打乱节奏）。

**B1 短句附和（规则层直接丢）**
```
收到
好的
ok
嗯嗯
哈哈哈
+1
谢谢！
知道了
666
```
→ 期待：全部不出现，「累计过滤」上涨。

**B2 纯表情 / 占位符**
```
[表情]
[图片]
[表情]
```
→ 期待：全部不出现。

**B3 长一点但没有信息量的（Jev 快判丢）**
```
第三章我一点没看
我也是
有人知道这题怎么做吗，求导那块卡住了
用链式法则，先对外层求导
懂了懂了 谢谢
有没有人在图书馆
帮我占个座
二食堂的红烧肉绝了
困了
刷到一个讲导数的视频，讲得挺清楚
```
→ 期待：全部不出现，且 **「Jev 快判过滤」数字上涨**（这是"快脑"在干活，没花 AI 的钱）。

> ⚠️ 别发带"点""号""周""会"这类时间词的闲聊（比如"这道题不会"里的"会"没事，
> 但"几点下课"会被当成候选）——那会变成"该不该过滤"的模糊案例，演示时不划算。

**B4 噪声里的"诱饵"：像通知但其实是闲聊**
```
明天的题难不难啊
这周还有几节课
```
→ 期待：可能留下也可能被丢——**主持可以现场解释**："这两条 Jev 拿不准，它会等 8 秒凑上下文再交给 AI，
不确定性优先交给慢脑，这是我们刻意留的安全边界。"

## 第八类 · `@` 规则（角色 D）

**D1 ★ 只 @ 别人 → 应该被彻底忽略**
```
【@张三 明天下午两点在 A301 小测，记得带计算器】
```
→ 期待：**永远不出现**（连数据库都不进）。要找一个群里真实存在的同学昵称。

**D2 不 @ 任何人 → 视为全体通知，照常处理**
```
【明天下午两点在 A301 小测，记得带计算器】
```
→ 期待：正常生成考试事件。

**D3 @全体成员 → 照常处理**
```
【@全体成员 明天下午两点在 A301 小测，记得带计算器】
```
→ 期待：正常生成考试事件。

**D4 @ 演示机那个号 → 照常处理（"@我"）**

→ 期待：正常生成考试事件。

## 第九类 · 边界与回归（角色 D）

**E1 ★ 幂等去重：把同一条原文发两遍**
```
【本周五 23:59 前把高数第三章习题 3-1 到 3-15 交到学习通，拍照上传即可】
```
（隔 1 分钟再发一遍完全一样的内容）
→ 期待：**事件没有变成两条**。这一步有**两个都算通过**的结果：
- **最优**：第二条被识破是重复提醒，整条丢掉 → 详情「查看来源」里仍只有第一条；
- **也可以**：详情「查看来源」出现**两条**原始消息，但事件仍然只有一条。

话术：*"群里有人重复转发通知，是常态。要么它认出这是同一个提醒不重复记录，
要么它把两条来源都挂到同一件事上——**两种结果都不会让你的日程变成两条。**"*

**E2 一批多条：两条通知挨着发（间隔 3 秒）**
```
【@全体成员 下周一上午 10:00 在 A301 交课设定题报告】
【@全体成员 下周三下午两点 A301 上机考试，占成绩 30%】
```
→ 期待：同一批里生成**两个**事件，一个都不少。

**E3 口语化时间**
```
【明晚八点老地方打球，不来就缺人了】
```
→ 期待：时间 = **明天 20:00**（演示"相对时间以消息发送时刻为基准"）。

**E4 超长消息不阻塞（塞一条很长的通知）**
```
【@全体成员 关于本学期期末考试安排的补充说明：本次期末考试时间为第十九周至第二十周，具体科目时间安排将在教务系统公布，请各位同学于下周五前登录教务系统确认自己的考试科目与时间，如有冲突请在下周三之前联系教务处王老师登记，逾期不再受理，另请注意考试须携带学生证和身份证，缺一不得入场，考试期间严禁携带任何电子设备】
```
→ 期待：能正常提出「考试安排」类事项，且**紧跟其后的消息照常处理**（不卡批）。

**E5 时间参照点：周一发的"下周三"是 9 天后，不是 2 天后**
```
【@全体成员 下周三上午 9 点在 B203 交材料】
```
→ 期待：落在**下一个自然周**的周三上午 9 点。专门用来验相对时间解析（建议排练时挑一天专门测这条）。

## 内部暗号（工作人员之间用，评委看不懂）

| 暗号 | 含义 |
|---|---|
| `#过` | 本轮发完了，交给页面 |
| `#停` | 先别发，页面卡住 / 主机在救场 |
| `#再来` | 重发上一条 |
| `#换` | 换到另一条话术，这条没触发 |

## 复制粘贴小技巧

1. **手机端**：把话术库存进手机备忘录 / 微信文件传输助手，按序号复制；
   或者让每个人只拿**自己那一段**（`02~05` 角色任务卡里已经按人分好了）。
2. **电脑端（更稳）**：QQ 桌面版登录**自己的号**，把话术存成 txt，一条一行复制发送——
   但注意演示机上只能登演示号，别在自己电脑上登演示号。
3. **占位符提前替换**：`@张三` 换成群里真实昵称，`@班级小助手` 换成演示机的 QQ 昵称，
   课程名换成课表里的真实课程名（如 `概率论与数理统计A`）。
4. **别一次复制多条**：QQ 会把换行一起发出去，变成一条超长消息（那反而变成 E4 的测试了）。
