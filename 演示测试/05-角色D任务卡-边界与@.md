# 角色 D 任务卡 · 边界与 @（群里的测试员）

> **你的定位**：你专门发"不好处理"的消息，用来证明系统的**边界是清楚的**：
> 谁的话被当成通知（不 @ / @全体 / @我），谁的话被无视（只 @ 别人）；
> 同一条转发两遍会不会变成两条日程；超长消息会不会把整条流水线卡死。
>
> 你的每一条消息都对着一个**技术亮点**，主持人会站在你旁边解释。

- 你的 QQ 昵称建议改成：`刘洋`（普通同学）或 `测试员小 D`
- 你要发的全部内容在 `01-话术库` **第八、九、十类**
- 时长：四段，穿插全场，每段 1~2 分钟

## 第一段 · `@` 规则（最能体现"工程细节"的 3 分钟）

**发法**：三条一组，**每条之间等 15 秒**，让主持人有时间指着页面说"在 / 不在"。

### 第 1 步 · 只 @ 别人 → 应该被彻底忽略

```
【@张三 明天下午两点在 A301 小测，记得带计算器】
```
（把 `张三` 换成群里真实存在的同学昵称）

**等 15 秒，让主持人刷新页面** → 期待：**它不在**。一个字都没有。

### 第 2 步 · 完全不 @ → 视为全体通知，照常处理

```
【明天下午两点在 A301 小测，记得带计算器】
```
→ 期待：正常生成考试事件。

### 第 3 步 · `@全体成员` → 照常处理

```
【@全体成员 明天下午两点在 A301 小测，记得带计算器】
```
→ 期待：正常生成考试事件。

### 第 4 步（可选）· @ 演示机那个号 → 照常处理

```
【@班级小助手 明天下午两点在 A301 小测，记得带计算器】
```
（把 `班级小助手` 换成演示机登录的 QQ 昵称）

> **主持人的解释**：*"在班级群里，@ 某个人通常意味着'这条只跟他说'。
> 我们只处理'对全体的话'——不 @ 的、@全体的、@我自己的；
> 只 @ 别人的，连数据库都不进。这不是妥协，这是隐私边界。"*

## 第二段 · 幂等去重（"重复转发不会变成两条日程"）

**时机**：主持人说"群里经常有人重复转发通知"。

### 第 1 步 · 原样发一遍

```
【本周五 23:59 前把高数第三章习题 3-1 到 3-15 交到学习通，拍照上传即可】
```

### 第 2 步 · 等 60 秒，**再原样发一遍**（一个字都不能改）

```
【本周五 23:59 前把高数第三章习题 3-1 到 3-15 交到学习通，拍照上传即可】
```

→ 期待：**事件没有变成两条**。两个结果都算通过：
- **最优**：第二条被识破是"重复提醒"而整条丢掉（详情里来源仍是一条）；
- **也可以**：来源里出现两条原文，但事件仍然**只有一条**。

主持的话术：*"同一条转发多少遍，你的日程上还是一件事。"*

> 想把这个结论验得更死：在「演示」页用「粘贴聊天记录」把**同一段文本**导入两次，
> 结果一样——因为消息 id 相同，第二遍直接不入库。

> 想让效果更硬：**在「演示」页用「粘贴聊天记录」把同一段文本导入两次**，结果也一样。

## 第三段 · 抗压与边界（证明"不会卡死"）

### E2 · 一批里两条通知（间隔 3 秒）

```
【@全体成员 下周一上午 10:00 在 A301 交课设定题报告】
```
等 3 秒
```
【@全体成员 下周三下午两点 A301 上机考试，占成绩 30%】
```
→ 期待：**两条都成事件**，一条不少。

### E4 · 超长消息不阻塞

```
【@全体成员 关于本学期期末考试安排的补充说明：本次期末考试时间为第十九周至第二十周，具体科目时间安排将在教务系统公布，请各位同学于下周五前登录教务系统确认自己的考试科目与时间，如有冲突请在下周三之前联系教务处王老师登记，逾期不再受理，另请注意考试须携带学生证和身份证，缺一不得入场，考试期间严禁携带任何电子设备】
```
→ 期待：能正常提出一个"考试安排"类事项；**紧接着的测试步骤照常进行，不卡顿**。
主持的话术：*"塞一条乱码或超长文本进去，整批不会卡死——失败的只是那一条。"*

### E3 · 口语化时间

```
【明晚八点老地方打球，不来就缺人了】
```
→ 期待：时间 = **明天 20:00**。

### E5 · 时间参照点（建议排练时专门测）

```
【@全体成员 下周三上午 9 点在 B203 交材料】
```
→ 期待：落在**下一个自然周**的周三（周一发的"下周三"是 9 天后，不是 2 天后）。

## 第四段 · 课表联动（"下节课"落进课表）

**前置**：测试群在「群管理」里已绑定课程（课程名与课表完全一致）。

### T1 · 下节课

```
【@全体成员 下节课小测，考第三章，提前十分钟到】
```
→ 期待：时间 = 本群绑定课程**下一次上课**的时间；**地点 = 课表里那门课的教室**（消息里没说教室）。

### T2 · 只说课程名

```
【概率论下次课交作业，第一章到第三章的课后题】
```
→ 期待：时间落到该课程下一次课。

主持的话术：*"它知道你这门课什么时候上、在哪上——所以'下节课'不用你说时间地点。"*

## 救场话术

| 情况 | 你怎么说 / 怎么做 |
|---|---|
| 只 @ 别人的那条**居然出现了** | 这是明确 bug，立刻记下来。主持："@ 规则这条我们回去核对，多谢发现" |
| 重复发变成了两条 | 记 bug。主持："事件合并的判断阈值需要再调" |
| "下节课"没落到教室 | 先确认「群管理」里绑的课程名和课表里的**字完全一样**（差一个空格都不行） |
| 超长消息之后卡住了 | 让群里安静 20 秒；仍不动就切「演示」页用回放继续，保住节奏 |
| 主持说"停" | 立刻停 |
