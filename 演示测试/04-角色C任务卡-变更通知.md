## 第一段 · 改期与补充要求（3~5 分钟）

### 第 1 步 · 改期（**核心验收点**）

**时机**：主持人说"现在班长在群里发了一条新通知"，并且**屏幕上正显示着那张小测卡**。

```
【@全体成员 小测改到周五下午两点，教室改 A203】
```

**发完等 15 秒**，让页面变化，然后主持会点开这张卡讲三件事：
1. **还是同一张卡片**，没有多出第二条；
2. 卡片上出现「已按最新通知更新」；
3. 详情 →「变更记录」能看到 `~~旧时间~~ → 周五 14:00`、`~~A301~~ → A203`。

> 这是需求文档里写的 `reschedule` 场景，也是整个产品的技术核心（事件状态机 + 合并）。
> **如果你只演一个动作，就演这个。**

### 第 2 步 · 补充要求（验证"要求是合并不是覆盖"）

**时机**：主持说"群里后来又补充了要求"。

```
【另外小测要带草稿纸，计算器别忘了】
```

→ 期待：详情里的「要求」= **原来的"带计算器和学生证" + 新的"带草稿纸、计算器"**，
旧要求**不能丢**（这是需求里明确写死的规则）。

### 第 3 步 · 连续改第二次（验证变更记录会叠加）

```
【@全体成员 小测再推迟一天，改到周六上午十点，教室换成 A305】
```

→ 期待：同一张卡片，变更记录里**累计两条**；最终时间 = 周六 10:00、地点 A305。

### 第 4 步 · 改会议地点（另一类事件也能改）

**时机**：主持人说"会议也能改"。

```
【班会改到 B301，时间不变，还是周四晚上 19:00】
```

→ 期待：蓝色会议卡的地点变 B301，**时间保持 19:00 不变**（说明只覆盖真正变了的字段）。

### （可选）第 5 步 · 把模糊时间改精确

```
【奖学金材料截止时间明确一下，是下周一上午 11:00，不是全天】
```

→ 期待：DDL 从"当天 24:00"精确到 11:00。

## 第二段 · 取消（3 分钟）

**顺序很重要**：先取消一件"独立的、没被改过的"事项（体测），
再演"取消后重新安排"，最后才取消前面改过的那张卡。

### 第 1 步 · 取消体测补测

**时机**：主持人说"现在看取消"，并且 `G3`（下周三 10:00 体测补测）已经在页面上。

```
【@全体成员 下周三的体测补测取消了，具体时间等通知】
```

→ 期待：绿色那张卡状态变成「已取消」。

### 第 2 步 · 取消后重新安排 → **应该生成新事件**

```
【@全体成员 体测补测重新安排在下下周一上午 9 点，地点 B 座 312，还是带校园卡】
```

→ 期待：出现一条**新的**活动卡片（下下周一 09:00），旧的那条仍然是「已取消」。
主持的话术：*"被取消的事项后来复活，是一条新记录——历史不会被改写，这也符合现实。"*

### 第 3 步 · 取消一场低等级活动

```
【周五下午的人工智能讲座取消了，改期再通知】
```

→ 期待：绿色那张变「已取消」。（低等级事项同样支持取消。）

### 第 4 步 · 取消那张被改过两次的小测卡（收尾，最有戏剧性）

```
【@全体成员 周六的小测取消了，等老师重新安排】
```

→ 期待：那张已经改过两次时间的卡片变成「已取消」，**变更记录里能看到完整的生命周期**：
创建 → 改到周五 → 改到周六 → 取消。

## 跟主持人的配合

| 主持人的话 | 你的动作 |
|---|---|
| "现在班长在群里发了新通知" | 发 `C1`，然后**闭嘴等 15 秒** |
| "后来又补充了要求" | 发 `C2` |
| "还能再改一次" | 发 `C3` |
| "如果这件事不办了呢" | 发 `X1`（取消） |
| "后来又决定办了" | 发 `X2`（重新安排） |
| "最后把它彻底取消" | 发 `X4` 或第 4 步 |

**你最重要的纪律**：**发完就停。** 你发的改期消息需要"群里安静 3 秒"才会被处理，
你多接一句"收到"，就多等几秒。

## 救场话术

| 情况 | 你怎么说 / 怎么做 |
|---|---|
| 改期后**多出了一条新卡片**（合并失败） | 这是要记录的 bug。主持临场话术："低置信度时它会宁可新建并标『待确认』，避免错误合并——这条我们回来核对" |
| 改期后页面**没变** | 先等 15 秒；仍不变就重发一次，把"周五下午两点"改成"明天下午三点"这种更明确的说法 |
| 变更记录里少了某个字段 | 顺势讲："它只记录**真正变了**的字段，没变的不写噪音" |
| 取消后卡片还在 | 确认状态文字是不是「已取消」（卡片不会消失，这是设计：它要能被追溯） |
| 主持说"停" | 立刻停，让群里安静 |
